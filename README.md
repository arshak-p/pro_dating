# Pro Dating

A Django prototype of a dating website with a multi-step sign-up.

## What is in it
- Pages: **Home**, **About**, **Contact**.
- Multi-step **sign-up**: personal details, job details and job status.
- Django app `home` with models, views, URLs and HTML templates.

## Tech stack
Python, Django, HTML, CSS.

## Run it locally
```bash
pip install django
python manage.py migrate
python manage.py runserver
```
Then open http://127.0.0.1:8000.

## Status
Early prototype. Matching, profiles and messaging are not built yet.
